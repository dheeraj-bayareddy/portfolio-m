# Dheeraj Kadadalamari Bayareddy — Portfolio

Live site: **[dheerajbayareddy.in](https://www.dheerajbayareddy.in/)**

Personal portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS. Features dark/light theme switching, EN/DE language toggle, glassmorphism UI, and sections for About, Experience, Projects, and Skills.

## Tech Stack

- [Next.js](https://nextjs.org) 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Deployed on [Vercel](https://vercel.com)

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Project Structure

- `app/` — pages and routes (App Router)
- `components/` — reusable UI components
- `data/` — content for projects and experience (edit these to add new entries)
- `lib/` — theme, language, and i18n logic
- `app/api/chat/` — placeholder route for a future chatbot feature
